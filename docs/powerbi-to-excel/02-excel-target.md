# 二、准备 Excel 目标文件

这是最容易被忽略、却最常导致流报错的一步。

## 1. 建立文件

1. 新建 `PowerBI_Log.xlsx`。
2. 上传到 **OneDrive for Business** 或 **SharePoint 文档库**（例如 `/Documents/PowerBI/`）。

## 2. 建立表头

在 `Sheet1` 第一行写入表头，列定义见下表（也可直接使用
[`excel/TB_Log_header.csv`](excel/TB_Log_header.csv) 作为表头模板）：

| 列名 | 类型 | 说明 |
| --- | --- | --- |
| `记录时间` | 日期时间 | 本次写入的北京时间，来自 `varRunTime` |
| `日期` | 日期（`yyyy-MM-dd`） | 业务日期，用于去重与筛选 |
| `区域` | 文本 | 维度示例 |
| `销售额` | 数值（2 位小数） | 度量值示例 |
| `订单数` | 数值（整数） | 度量值示例 |
| `运行ID` | 文本 | 本次运行批次的 GUID，便于追溯与回滚 |

> `日期` 与 `运行ID` 是去重与追溯的关键列，即使业务上不需要也建议保留。

## 3. 转成"表格"（Table）

1. 选中表头及下方一行区域。
2. **插入 → 表格**，务必勾选"**包含标题**"。
3. 在"表设计"里把表名改为 **`TB_Log`**。

> Power Automate 的 Excel Online (Business) 连接器只能操作"表格(Table)"，
> 不能直接操作普通单元格区域。没有表格时，动作的表下拉框会是空的。

## 4. 设置列格式

- `记录时间`：设为"日期时间"格式（如 `yyyy-mm-dd hh:mm:ss`）。
- `日期`：设为"日期"格式（`yyyy-mm-dd`）。
- `销售额`：数值，2 位小数。
- `订单数`：数值，0 位小数。
- `区域` / `运行ID`：文本。

如果不设置格式，写入的数字很可能被当作文本，导致后续透视表/公式失效。
在流里也要配合使用 `float()` / `int()` 做类型转换，见
[`03-flow-route-a.md`](03-flow-route-a.md#7-写入内容设计)。

## 5. 容量与归档建议

- 单表建议控制在 **5 万行**以内；Excel 连接器在几万行以上会明显变慢。
- 超出后按月分文件：`PowerBI_Log_2026-08.xlsx`，用单独的归档流每月复制并清空。
- 多个流不要并发写同一个文件，否则会出现文件锁定错误；必要时把
  `Apply to each` 的并发度设为 1，或按业务拆分文件。
